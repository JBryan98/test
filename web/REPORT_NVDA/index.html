07 · Interpretación

Auditoría y Glosario

Qué significa cada métrica del informe y cómo se calcula, para lectura no técnica.

1 · KPIs generales del modelo

¿aprende algo la clasificación?
OOF (Out-of-Fold)

Predicciones del modelo hechas sobre bloques que nunca vio durante su entrenamiento, respetando el orden temporal (walk-forward). Es la medida más honesta de aprendizaje.

HOLDOUT

Bloque final del histórico reservado y evaluado una sola vez. Simula lo que habría pasado al desplegar el modelo en el último tramo.

F1 macro

Promedio sin ponderar del F1 de BUY, HOLD y SELL. Obliga a que las tres clases funcionen; el baseline de mayoría obtiene 0.182.

ROC-AUC OVR

Calidad de ordenamiento de las probabilidades (one-vs-rest). 0.50 = azar; 0.55-0.60 = señal débil; 0.60-0.65 = señal razonable.

Precision / Recall

Precision = de las señales emitidas, cuántas fueron correctas. Recall = de las oportunidades reales, cuántas se detectaron.

Matriz de confusión

Tabla real-vs-predicho. Se normaliza por fila: cada celda es el % de veces que una clase real se clasificó como otra.

BUY / HOLD / SELL

Etiquetas del target: BUY si el retorno futuro supera +τ, SELL si cae por debajo de −τ, HOLD en la zona intermedia.

τ (tau) y horizonte H

Umbral de movimiento relevante (±0.8%) y horizonte de predicción (4 barras de 1 hora). Se eligen para equilibrar las clases y superar el ruido.

Purging y embargo

Se eliminan del entrenamiento las filas cuyo futuro solapa con el test (purge) y se deja un margen posterior (embargo), evitando fuga de información.

Sesgo de selección

El bloque holdout también se usó para comparar variantes (H=3/4, tau 0.6-0.8%), por lo que sus métricas son optimistas. Para una validación estricta conviene reservar un bloque nuevo o usar walk-forward anidado.

2 · KPIs financieros

¿la señal gana dinero después de costes?
Sharpe Ratio

Retorno medio por unidad de volatilidad, anualizado ×√1,764 barras. Valores > 0 indican retorno ajustado por riesgo positivo.

Sortino Ratio

Como Sharpe pero solo penaliza la volatilidad negativa (riesgo bajista).

Max Drawdown

Mayor caída desde un máximo de equity hasta el mínimo posterior. Mide el peor escenario histórico.

Calmar / Win Rate / Profit Factor

Calmar = retorno anual / |MDD|. Win Rate = % de operaciones ganadoras. Profit Factor = ganancias brutas / pérdidas brutas.

IC Spearman

Correlación entre el score continuo (p_BUY − p_SELL) y el retorno futuro real. Mide si la señal ordena bien las oportunidades.

t-stat del retorno

Retorno medio dividido por su error estándar. Si |t| < 2, la ganancia media no es estadísticamente distinguible de cero con la muestra disponible. Es la prueba de significancia del Sharpe.

Costes y slippage

Cada cambio de posición paga comisión + deslizamiento. El informe usa 0.1% por cambio (conservador del proyecto) y muestra sensibilidad; en una acción líquida como NVDA el coste realista ronda 0.02%.

Sharpe con barras planas

El Sharpe se calcula sobre todas las barras (incluidas las de posición 0). Si la estrategia está fuera del mercado la mayor parte del tiempo, el ratio puede inflarse; el t-stat corrige esa lectura.

3 · Indicadores y datos

variables y calidad de los datos
RSI / MACD / Bollinger / ATR

Indicadores técnicos calculados con ventanas de barras de 1 hora: RSI-14 mide fuerza relativa; MACD, el cruce de medias; Bollinger, posición dentro de la volatilidad; ATR, el rango medio (volatilidad).

VWAP y ORB

VWAP = precio medio ponderado por volumen de la sesión. ORB = rango de la primera hora; su ruptura es una señal clásica de momentum intradía.

Beta / Correlación / Alpha

Beta = cuánto amplifica NVDA los movimientos del sector (SOXQ); correlación = grado de acople; alpha = la parte del retorno que NVDA hace por sí sola.

Volumen relativo

Volumen de la barra ÷ media de 20 barras previas. Se usa en lugar del volumen absoluto porque la columna del proveedor cambia de unidades entre años y no es comparable.

Impacto de noticias

Impacto = relevancia × |sentimiento|. Terciles: Alto (rojo), Medio (naranja) y Bajo (verde). Se agrupan por signo positivo/negativo.

Zona horaria

Los cálculos internos usan UTC (IBKR/Alpha Vantage); todas las tablas y CSV del informe se muestran en hora de Nueva York (ET) para coincidir con el horario de mercado.

Limitaciones

Con datos horarios y noticias heterogéneas, un AUC de ~0.60 es una señal modesta: no garantiza rentabilidad. Los costes y el slippage reales pueden ser mayores.
